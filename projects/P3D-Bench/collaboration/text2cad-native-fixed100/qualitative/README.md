# Text2CAD native figure materials

Six existing figure cases, using Text2CAD native JSON rather than the general models' OpenSCAD. Each record binds the saved program, mesh, renders, original condition, new QA answers and score. No example was chosen by its score; no asset was redrawn.

Follow each record's own GT hash, especially UID0093/00934405. Different model outputs must not be displayed against a shared GT unless their saved GT geometry is verified equal. The two original figure cases outside fixed100 remain outside scope. Model-level rankings and buckets must use the companion native per-format table, not an average of diagnostic per-case Judge or Geometry.

The invalid/ directory preserves all 11 selected invalid programs and their saved error evidence (9 descriptive, 2 parametric). No new failure taxonomy was assigned.
